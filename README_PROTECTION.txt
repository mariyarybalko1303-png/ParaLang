Ви розробили унікальну навчальну мову ParaLang (v26). Щоб дати студентам 
доступ до виконання лабораторних робіт і одночасно зробити так, щоб вони 
не змогли відкрити та вкрати ваш Python-код для завантаження на GitHub,
скористайтеся двома готовими рішеннями, які ми щойно створили для вас:

---------------------------------------------------------------------
ПІДХІД №1: Використання готового бінарного байт-коду (файл: "paralang-v26.pyc")
---------------------------------------------------------------------
Я щойно скомпілював ваш інтерпретатор у машинний Python-байткод:
👉 Файл "paralang-v26.pyc" повністю бінарний. Якщо студент спробує 
   відкрити його у Блокноті чи VS Code, він побачить лише нечитабельні символи.
👉 Він працює на будь-якій системі (Windows, Linux, macOS), де встановлено Python 3.12.

Як його використовувати:
1. Завантажте файл "paralang-v26.pyc" з панелі Studio.
2. Перейменуйте його на "paralang.pyc" (без суфіксу версії).
3. Покладіть його у робочу папку (наприклад, на диску "D:\").
4. Тепер Jupyter-ядро "paralang_kernel.py" зможе імпортувати його командою 
   "from paralang import Lexer, Parser..." безпосередньо з цього бінарного файлу!
   Студенти зможуть писати коди, але оригінальний Python-код залишиться невидимим.

---------------------------------------------------------------------
ПІДХІД №2: Компіляція у самостійний Windows EXE (файл: "compile_to_exe.bat")
---------------------------------------------------------------------
Якщо ви хочете перетворити мову ParaLang у справжній закритий Windows executable 
файл (.exe), скористайтеся автоматичним Windows-скриптом "compile_to_exe.bat":

Як скомпілювати:
1. Завантажте файли "paralang-v26.py" (оригінал) та "compile_to_exe.bat" на комп'ютер.
2. Покладіть їх в одну папку (наприклад, на диску "D:\").
3. Двічі клацніть лівою кнопкою миші на "compile_to_exe.bat".
4. Скрипт перевірить Python, встановить необхідний інструмент збирання 
   (PyInstaller або Nuitka за вашим вибором) та скомпілює код.
5. Готовий файл "paralang.exe" буде збережено у папці.

Який метод компіляції обрати в скрипті:
- Метод [1] (PyInstaller) — Швидкий та безвідмовний. Створює один файл, 
  який легко запускати.
- Метод [2] (Nuitka) — Максимальний захист. Повністю транслює ваш Python-код 
  у мову C++ та компілює його у машинний бінарний код. Цей файл неможливо 
  декомпілювати назад! (Потребує встановленого на Windows компилятора C++, 
  наприклад Microsoft Visual Studio C++ або MinGW).
